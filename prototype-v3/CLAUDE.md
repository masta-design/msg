# Проект: прототип раздела «Сервисы» сайта МСГ (этап 1)

Кликабельный прототип (HTML + CSS + JS) для демонстрации клиенту и согласования структуры. Не рабочий сайт.
Основа — ТЗ `TZ_prototip_MSG_etap1.md` (если лежит в папке).

## Как устроен проект
- HTML генерируется скриптом. **Не править файлы в `dist/` руками** — правки вносятся в исходники, затем `python3 build.py`.
- `blocks.py` — библиотека секций S01–S29: одна функция = одна секция.
- `build.py` — хедер (G01), крошки, футер (G02), контент страниц P0–P7, сборка.
- `styles.css` — стили, токены в `:root`. `app.js` — интерактив.
- Результат: `dist/msg-prototype/` (многостраничная версия + zip) и `dist/msg-prototype.html` (одностраничная).

## Правила
1. Страницы P1–P6 собираются только из секций библиотеки.
2. Новая секция сначала добавляется в `blocks.py` как универсальный, потом показывается на демо-странице P7 (`p_blocks` в `build.py`) с аннотацией `ann(...)`, и только затем используется на страницах.
3. Визуал — проектный, не дизайн: шрифт Inter; синий #2457F5 только для кнопок, ссылок, активных состояний; ширина 1400px.
   Текст: 3 размера (`--fs-s` 14px, `--fs-m` 16px по умолчанию, `--fs-l` 18px), 3 толщины (`--fw-regular` 400, `--fw-medium` 500, `--fw-bold` 700), 3 цвета (`--text-primary` #111, `--text-secondary` #555, `--text-link` синий) и те же 3 для тёмного фона (`--text-inverse-*`). Новые размеры, толщины и цвета текста не добавлять. Вне системы только заголовки h1–h4, крупные цифры/цены/телефоны, иконки и цвета валидации (`--text-error` красный для ошибок, `--text-success` зелёный для успеха).
   Бейджей с фоном на сайте нет (ни в hero, ни в карточках, ни у тарифов), в карточках услуг нет ссылки «Подробнее →»: карточка целиком является ссылкой.
   Терминология: продукты МСГ называем «сервисы» (не «услуги»); «услуги» — только состав внутри сервиса. Источники фактов: `references/` (презентация, расшифровки, скетчи), ТЗ вторично; цифры, скидки, цены и юридические формулировки без подтверждения в источниках не добавлять.
4. Изображения — серые заглушки `ph('что изображено, пропорции')`. Иконки — эмодзи и символы.
5. Везде, где показана цена (hero D, таблица сравнения тарифов), всегда сноска об ориентировочных ценах (`PRICE_NOTE`).
6. Кнопка «Оставить заявку» в хедере одинакова на всех страницах.
7. Подзаголовок и описание под заголовком (`p.lead`, `p.muted`) из одного предложения — без точки в конце. Правило применяется автоматически при сборке (`no_dot` в `blocks.py`); при нескольких предложениях точки остаются.
8. Отступы секций: у всех одинаковые (`--sec-py`), границ между секциями нет. Соседние секции с одним фоном не складывают отступы — расстояние между ними `--same-gap`; при смене фона остаются оба отступа; после hero до белой секции — `--hero-gap`. Реализовано CSS-селекторами соседей, на странице библиотеки класс `sec-join` ставит `app.js`.
9. Сайт адаптивный, но отрисовывается и проверяется в первую очередь на 1400px.

## Проверка после правок
`python3 build.py`, затем открыть `dist/msg-prototype/services.html` в браузере и проверить изменённые страницы и `blocks.html`.
