# МСГ — исходники прототипа (этап 1)

Прототип генерируется скриптом, HTML руками не правится.

- `blocks.py` — библиотека секций S01–S29 (разметка каждой секции).
- `build.py` — хедер, футер, хлебные крошки, контент страниц P0–P7, сборка.
- `styles.css` — все стили (токены цветов и шрифтов в начале файла).
- `app.js` — интерактив.

Сборка: `python3 build.py` → папка `dist/`:
- `dist/msg-prototype/` — многостраничная версия (+ `msg-prototype.zip`);
- `dist/msg-prototype.html` — одностраничная версия для публикации.

Требуется Python 3, сторонние библиотеки не нужны.
